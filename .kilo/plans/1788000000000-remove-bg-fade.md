# Remove Background Text Fade Behavior

## Goal
Remove the fading ease-out animation from background text. Words should stay visible at their set opacity without cycling/fading/moving.

## Current State
- Lines 443-472 in `index.js` contain a `setInterval` that runs every 60s
- Every 60s, 5 random words fade out over 45s, move to new positions, then fade back in
- This creates a subtle cycling effect that the user wants removed

## Implementation Steps

### 1. Remove the fading setInterval block
Delete lines 443-472 in `index.js`:
```javascript
/* ===== Every 60s: slowly cycle 5 words to new positions ===== */
setInterval(() => {
  const bg = document.querySelector(".background");
  if (!bg || !bg.classList.contains("reveal")) return;
  const allWords = [...bg.querySelectorAll(".bg-word")];
  if (allWords.length < 5) return;

  const shuffled = allWords.sort(() => Math.random() - 0.5);
  const selected = shuffled.slice(0, 5);

  selected.forEach((span, i) => {
    const delay = i * 5000;

    setTimeout(() => {
      span.style.transition = "opacity 45s ease";
      span.style.opacity = "0";

      setTimeout(() => {
        span.style.transition = "none";
        span.style.left = `${-5 + Math.random() * 110}%`;
        span.style.top = `${-5 + Math.random() * 110}%`;

        setTimeout(() => {
          span.style.transition = "opacity 45s ease";
          span.style.opacity = span.dataset.finalOpacity || "0.45";
        }, 100);
      }, 45000);
    }, delay);
  });
}, 60000);
```

### 2. No other changes needed
- Background words will keep their initial random positions
- Words remain at their set opacity
- New messages from polling still add new words to background
- Background blur effect during text animation still works
